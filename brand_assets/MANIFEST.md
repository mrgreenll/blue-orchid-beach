## Quality gate applied

- **Resolution:** long edge ≥ 1200 px = OK for hero/feature; 800–1199 px = "thumbnail only" (flagged);
  rejected as redundant if a higher-res alternative existed.
- **Sharpness:** rejected blurry / heavy-compressed / noisy night shots.
- **Subject:** rejected back-of-house corridors w/ A/C units, utilitarian TV/closet frames, overcast +
  cluttered scenes, near-duplicate room repeats, and two rooms with an off-brand profanity wall poster.
- **No** booking-platform UI overlays or watermarks were present (gallery served clean originals).
